# Security

This repository contains documentation, validation scripts and public product
captures. It does not contain the CholloGas application, backend, credentials or
production configuration.

If you find sensitive information, a privacy issue or a weakness in the public
material, please do not open a public issue. Report it privately to
[soporte@ogamlabs.com](mailto:soporte@ogamlabs.com) with the affected path and
the minimum detail needed to reproduce the concern.

Product support belongs at [chollogas.ogamlabs.com](https://chollogas.ogamlabs.com),
not in this repository's security channel.
